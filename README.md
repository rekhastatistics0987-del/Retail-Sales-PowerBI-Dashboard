# Retail Sales & Inventory Analytics Dashboard

## Project Overview

This project analyzes over 100,000 retail transactions using Power BI.

The dashboard provides insights into:

- Sales Performance
- Profitability Analysis
- Product Performance
- Regional Trends
- Customer Segments
- Operational Efficiency

## Tools Used

- Power BI
- DAX
- Power Query
- Excel

## Key Metrics

- Total Sales: ₹2.51 Billion
- Total Profit: ₹375.5 Million
- Total Orders: 100,000+
- Units Sold: 549,000+

## Dashboard Features

- Executive Dashboard
- Product Analytics Dashboard
- Discount vs Profit Analysis
- Waterfall Chart
- Decomposition Tree
- Interactive Filtering

## Key Insights

- West region generated the highest profit.
- Electronics contributed the highest sales.
- High discounts reduced profitability in several categories.
- Top products generated a significant share of revenue.
